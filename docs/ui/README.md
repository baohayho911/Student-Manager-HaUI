# Mẫu giao diện

- Đăng nhập: ảnh trường toàn màn hình, form trắng giữa trang, logo HaUI, nhãn One HaUI, nút đen, bật/tắt xem mật khẩu.
- Sau đăng nhập: sidebar trắng bên trái, mục đang chọn nền kem, header tài khoản, nền xám nhạt, banner xanh nhạt, bảng và biểu mẫu thống nhất.
- Menu theo vai trò trong use case mới. Không sao chép nhật ký và các chức năng ngoài phạm vi từ ảnh giao diện cũ.
- Ảnh được giữ tại public/images; nguồn tái sử dụng từ ứng dụng/ảnh mẫu người dùng cung cấp, không đại diện cho xác nhận hoặc phát hành chính thức của trường.
